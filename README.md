# منصة الحرباوي للامتحانات — Firebase

## ما تم تنفيذه في هذه النسخة
- تحويل المشروع من Supabase إلى Firebase SDK.
- تسجيل الدخول وإنشاء حساب طالب باستخدام Firebase Authentication.
- إنشاء ملف مستخدم تلقائيًا في Firestore بدور `student`.
- لوحة تحكم عربية متجاوبة.
- قراءة الامتحانات المنشورة للطلاب، وقراءة كل الامتحانات للمدير/المدرس.
- إنشاء امتحان كمسودة مع أسئلة اختيار من متعدد ومقالية.
- فصل مفاتيح الإجابة في مجموعة محمية لا يقرأها الطلاب.
- نشر الامتحان أو إلغاء نشره.
- ملف قواعد Firestore أولي في `firestore.rules`.

## إعداد المشروع
1. فك ضغط الملف.
2. انسخ `.env.example` إلى `.env` في جذر المشروع.
3. املأ القيم الست من Firebase Web App config.
4. من Firebase Console فعّل Authentication > Email/Password.
5. أنشئ Cloud Firestore Database.
6. انشر قواعد `firestore.rules` من صفحة Firestore > Rules.
7. نفّذ:
   - `npm install`
   - `npm run dev`

## ترقية حساب المدير الأول
حسابات التسجيل العامة تُنشأ بدور `student` فقط. بعد إنشاء حسابك من صفحة الدخول:
1. افتح Firestore > Data.
2. افتح مجموعة `users`.
3. افتح المستند الذي يحمل UID الخاص بحسابك.
4. غيّر قيمة `role` من `student` إلى `admin`.
5. سجّل الخروج ثم الدخول مرة أخرى.

لا تمنح دور admin لأي حساب غير موثوق. لا يمكن إنشاء مدير من نموذج التسجيل العام.

## تنبيه أمني مهم
إعدادات Firebase Web App ليست كلمة مرور، لكن قواعد Firestore هي التي تحمي البيانات. انشر القواعد المحدّثة قبل إدخال بيانات طلاب حقيقية. مفاتيح الإجابة محفوظة في مجموعة `examAnswerKeys` المخصصة للمدير والمدرس فقط. هذه النسخة لا تتضمن بعد شاشة أداء الامتحان وتسليم الإجابات والتصحيح والدرجات؛ هذه هي المرحلة التالية. كما أن قواعد Storage لم تُضبط بعد لأن رفع صور الإجابات سيُضاف لاحقًا.

## ملاحظات
- ملف `.env` لا يُرفع إلى Git؛ وهو مستثنى في `.gitignore`.
- لا تضع Service Account أو private key داخل تطبيق الويب.
