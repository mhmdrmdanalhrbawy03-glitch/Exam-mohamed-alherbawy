# منصة الحرباوي للامتحانات (نسخة كاملة وجاهزة للنشر)

## المميزات المدمجة في هذه النسخة
1. **إصلاح كامل لمشكلة الشاشة البيضاء والنشر على Vercel** (تضمين `vercel.json` وضبط `vite.config.ts` ومسارات الاستيراد).
2. **شاشة أداء الامتحان للطلاب**: عداد تنازلي للوقت، حل الأسئلة الاختيارية والمقالية، وتسليم الإجابات.
3. **تصحيح تلقائي فوري**: حساب درجة الطالب فور التسليم وعرضها له وتسجيلها في قاعدة البيانات.
4. **لوحة نتائج الطلاب**: عرض درجات كل طالب للمدرس/المدير، وعرض سجل الدرجات لكل طالب.
5. **إدارة كاملة للمدرس/المدير**: إنشاء امتحانات، نشر/إلغاء نشر، حذف، ومتابعة الطلاب المسجلين.

## طريقة التشغيل والنشر على Vercel بدون أي أخطاء:
1. ارفع هذا المجلد إلى مستودع GitHub جديد.
2. اربط المستودع بـ **Vercel**.
3. قبل الضغط على Deploy (أو من Settings > Environment Variables)، أضف المتغيرات الستة من مشروعك في Firebase:
   - `VITE_FIREBASE_API_KEY`
   - `VITE_FIREBASE_AUTH_DOMAIN`
   - `VITE_FIREBASE_PROJECT_ID`
   - `VITE_FIREBASE_STORAGE_BUCKET`
   - `VITE_FIREBASE_MESSAGING_SENDER_ID`
   - `VITE_FIREBASE_APP_ID`
4. من لوحة تحكم Firebase -> **Firestore Database** -> **Rules**، انسخ محتوى ملف `firestore.rules` وانشره.
5. لترقية حسابك إلى مدير (`admin`): سجل حساباً جديداً في الموقع، ثم افتح Firestore > `users` > مستند حسابك، وغيّر `role` إلى `admin`.
